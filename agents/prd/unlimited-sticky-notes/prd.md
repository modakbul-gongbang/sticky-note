# PRD: Unlimited Sticky Notes

## Goal

이호연이 이 Mac에서 Option+`로 즉시 꺼내 쓰는, 노트 수 제한이 없는 개인용 스티키 노트 앱을 설치해 Raycast Notes의 핵심 사용감을 유지하면서 서식과 이미지를 포함한 임시 메모를 로컬에서 빠르게 작성하고 다시 찾을 수 있게 한다.

Approval checklist:
- 핵심 범위는 단일 상시 위 창, Option+` 토글, 무제한 노트, 서식 및 이미지, 검색, 휴지통이다. (B1-B10)
- 앱은 이 Mac에 로컬 설치하며 전달 모드는 `local`이다. (D-18, B17)
- 설치 때 Raycast Notes 단축키만 이전하고 실패하면 원래 할당을 복원한다. (D-13, B14)
- 노트와 이미지는 외부로 보내지 않으며 공개 배포, 동기화, 업데이트 확인을 포함하지 않는다. (D-06, D-15, D-16)
- 마지막 시각적 완성도와 실제 사용감은 사용자가 확인한다. (B18)

## Non-goals

- 다른 Mac과 동기화하지 않는다. 여러 기기 사용 요구가 생기면 저장 및 충돌 정책과 함께 재검토한다. (D-06)
- 기존 Raycast 노트를 가져오지 않는다. 이전 요청이 생기면 Raycast가 공식적으로 제공하는 내보내기 형식을 기준으로 재검토한다. (D-12)
- 별도 백업 및 복원 파일을 만들지 않는다. 임시 메모가 장기 보관 자료가 되거나 Mac 교체 요구가 생기면 재검토한다. (D-16)
- 타인 대상 배포, App Store, 자동 업데이트를 포함하지 않는다. 공개 배포 요청이 생기면 서명, 공증, 업데이트 및 지원 정책과 함께 재검토한다. (D-09, D-15)
- 새 앱은 Raycast 설정을 상시 관리하지 않고 앱 삭제 시 기존 단축키를 자동 복원하지 않는다. 설치 이후 관리 요구가 생기면 공식 연동 수단이 생겼을 때 재검토한다. (D-13)
- 여러 노트를 별도 창으로 동시에 띄우지 않는다. 동시 비교 요구가 생기면 단일 창 원칙과 함께 재검토한다. (D-04)
- 노트 개수에 제품 제한을 두지 않지만 저장 장치 용량이 무한하다고 보장하지 않는다. 자원 부족은 저장 실패로 명확히 드러낸다. (D-02, D-17)

## Technical structure

새 Swift Package가 AppKit 기반 메뉴 막대 앱, 하나의 포커스 가능한 플로팅 패널, 시스템 전역 단축키, 로그인 실행 등록을 묶어 arm64 앱 번들로 만든다.
데이터 경계는 사용자 Application Support 아래의 노트별 RTFD 패키지와 원자적 메타데이터 인덱스뿐이며, 외부 서비스와 네트워크 권한은 없다.
설치 절차는 새 앱의 단축키 등록 결과를 확인하면서 보이는 Raycast 설정 화면에서 Notes 단축키 하나만 이전하고, 부분 실패 시 캡처한 원래 할당으로 되돌린다.
로컬 전달은 Swift CLI로 빌드하고 개인용 앱 번들을 서명해 Applications에 설치하며, 공개 배포 인프라나 서버를 추가하지 않는다.

## Risks

- 대상 Mac은 macOS 15.1이고 Option 단독 수정키 전역 단축키에 알려진 OS 회귀가 있으므로 Carbon 등록을 우선 사용하되 실제 OSStatus를 표시하고, 실패하면 권한이 필요한 이벤트 감지 대안을 명시적으로 안내하고 실제 대상 환경에서 판정한다.
- Raycast는 다른 앱이 단축키를 변경하는 공식 API가 없으므로 암호화된 내부 데이터베이스를 수정하지 않는다. 설치 증거는 보이는 설정 UI의 전후 상태와 실패 롤백으로 제한한다.
- 전체 화면, Space, 다중 모니터와 로그인 항목은 코드만으로 판정하지 않는다. 실제 대상 Mac에서 가능한 경로는 검증하고, 로그아웃이나 물리적 모니터 분리가 사용자 작업을 방해하면 미실행 범위를 명시한다.
- 휴지통 영구 삭제 검증에는 구현 과정에서 만든 테스트 노트만 사용하고 기존 사용자 노트는 삭제하지 않는다.
- 전체 Xcode가 선택되지 않았지만 Swift 6.0.3 CLI와 시스템 서명 도구는 사용할 수 있다. 구현은 Swift Package와 Apple 기본 프레임워크 범위로 유지하며 필요한 사용자 계정, 자격 증명 또는 구매는 없다.
